# Landing Kit — быстрые лендинги для easy-1c.ru

Стартовый набор, чтобы через Claude Code Desktop **быстро делать и публиковать
лендинги** в фирменном стиле «1С:Цифра», с формами заявок, письмами на почту,
хранением заявок (152-ФЗ) и Яндекс.Метрикой.

Первый готовый лендинг — под продукт **«Отдел ОКК»** (`index.html`).

---

## Что внутри

```
landing-kit/
├── index.html              # готовый лендинг «Отдел ОКК» (копируйте под новые продукты)
├── privacy.html            # политика конфиденциальности (шаблон 152-ФЗ)
├── assets/
│   ├── css/
│   │   ├── tokens.css       # ← ЕДИНЫЙ файл стиля: цвета, шрифты, отступы
│   │   └── styles.css       # вёрстка (трогать обычно не нужно)
│   ├── js/
│   │   └── form.js          # валидация формы + отправка + цель Метрики
│   └── img/                 # сюда кладите картинки (WebP/JPG)
└── api/
    ├── submit.php           # обработчик формы: письмо + запись заявки
    ├── config.example.php   # → скопировать в config.php и заполнить
    └── data/                # CSV с заявками (защищён .htaccess, не в git)
```

---

## Как это устроено (архитектура)

1. **Лендинг** — статические HTML/CSS/JS. Быстрые, адаптивные, легко правятся в Claude Code.
2. **Форма** отправляет заявку через `fetch` на `api/submit.php` — без перезагрузки страницы.
3. **PHP-обработчик** на вашем российском хостинге:
   - проверяет поля и согласие на обработку ПДн,
   - отсекает спам (honeypot + rate-limit),
   - **шлёт письмо** на почту домена,
   - **пишет заявку в CSV** прямо на сервере — данные не уходят за рубеж (152-ФЗ).
4. **Яндекс.Метрика** считает визиты и фиксирует цель `lead` при успешной отправке.

Ключевой принцип соответствия 152-ФЗ: персональные данные заявок остаются
на вашем сервере в РФ, есть галочка согласия и страница политики.

## Запуск за 15 минут

### 1. Верните HTTPS на домене (это отдельная и срочная задача)
Истёкший SSL чинится **бесплатно** через Let's Encrypt:
- В панели хостинга (Timeweb / Beget / Reg.ru / ISPmanager / cPanel) найдите
  раздел «SSL-сертификаты» → выпустить **Let's Encrypt** для домена → включить.
- Включите принудительный редирект `http → https`.
- Сертификат продлевается автоматически каждые 90 дней, покупать ничего не нужно.

### 2. Настройте почту
```bash
cp api/config.example.php api/config.php
```
В `api/config.php` укажите:
- `mail_to` — куда приходят заявки (напр. `info@easy-1c.ru`),
- `mail_from` — ящик **на вашем домене** (напр. `noreply@easy-1c.ru`), иначе
  письма уйдут в спам. Убедитесь, что у домена настроены записи **SPF и DKIM**
  (обычно включается в почтовом разделе панели хостинга).

### 3. Вставьте счётчик Яндекс.Метрики
В `index.html` найдите блок `Яндекс.Метрика` и замените `00000000` (в трёх местах:
`window.METRIKA_ID`, тег и `<noscript><img>`) на номер вашего счётчика.
Затем в Метрике создайте **цель** типа «JavaScript-событие» с идентификатором
`lead` — она будет срабатывать при каждой успешной заявке, и вы увидите конверсию.

### 4. Залейте файлы на хостинг
Скопируйте содержимое `landing-kit/` в нужную папку сайта (или поддомен, напр.
`okk.easy-1c.ru`) по FTP/SFTP или через файловый менеджер панели. Проверьте, что
PHP включён (обычно версия 7.4+). Откройте страницу, отправьте тестовую заявку —
письмо должно прийти, а строка появиться в `api/data/leads-ГГГГ-ММ.csv`.

## Как сделать новый лендинг

1. Скопируйте `index.html` → `новый-продукт.html`.
2. Попросите Claude Code переписать заголовки, тексты и блоки под новый продукт
   («перепиши hero и преимущества под продукт X, стиль сохрани»).
3. Поменяйте картинку в `assets/img/` и `<input name="source">` (чтобы в заявке
   было видно, с какого лендинга она пришла).
4. Стиль подтянется автоматически — он весь в `tokens.css`.

> Так как весь стиль в `tokens.css`, любой новый лендинг **из коробки совпадает**
> с брендом. Изменили цвет там — поменялось везде.

## Красивые адаптивные картинки

Используется `<picture>` с `srcset` — браузер сам берёт WebP и нужный размер:
- Кладите 2 версии по ширине (напр. `hero-800.webp`, `hero-1200.webp`) + JPG-фолбэк.
- Конвертация в WebP: Claude Code может подсказать команду (`cwebp` / онлайн),
  либо экспортируйте из редактора.
- Источники бизнес-изображений: фотостоки или AI-генерация (как приложенный постер).
  Держите единый визуальный тон: оранжевые акценты, светлый фон, аналитика/графики.

## Уведомления в Telegram (опционально)

Быстрее email. В `api/submit.php` раскомментируйте блок Telegram, а в `config.php`
добавьте `telegram_token` (от @BotFather) и `telegram_chat_id` (от @userinfobot).
Заявки будут дублироваться в чат мгновенно.

## Чек-лист перед публикацией

- [ ] HTTPS работает (Let's Encrypt), есть редирект с http.
- [ ] `config.php` создан, `mail_from` — ящик на домене, SPF/DKIM настроены.
- [ ] Тестовая заявка: пришло письмо + строка в CSV.
- [ ] Счётчик Метрики вставлен, цель `lead` создана и срабатывает.
- [ ] В `privacy.html` заменены реквизиты организации.
- [ ] Папка `api/data/` недоступна по прямой ссылке (проверьте — должна давать 403).

## Соответствие 152-ФЗ (кратко)

- ✅ Галочка согласия на обработку ПДн в форме (обязательна для отправки).
- ✅ Страница «Политика конфиденциальности» (`privacy.html`).
- ✅ Данные хранятся на сервере в РФ (ваш хостинг).
- ⚠️ Заполните реквизиты оператора в `privacy.html`. При серьёзных объёмах
  сбора ПДн может потребоваться уведомление в Роскомнадзор — уточните у юриста.
