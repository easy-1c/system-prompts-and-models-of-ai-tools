# SETUP — процесс под ваш кейс

**Среда:** Claude Code Desktop (локально, Mac) · поддомен **okk.easy-1c.ru** · публикация по **SFTP/FTP**.

Этот файл — карта процесса. Делается один раз (разделы A–B), дальше повторяется цикл (раздел C).

---

## A. Разовая настройка хостинга (в панели хостинга)

1. **Создать поддомен** `okk.easy-1c.ru` → указать его корневую папку (запомните путь,
   напр. `/home/USER/okk.easy-1c.ru/public_html`). DNS-запись поддомена обычно
   создаётся автоматически; если нет — добавьте `A`-запись `okk` на IP сервера.
2. **Выпустить SSL** для поддомена: раздел «SSL» → **Let's Encrypt** → домен
   `okk.easy-1c.ru` → включить + редирект http→https. (Тот же способ закроет и
   истёкший SSL на основном easy-1c.ru — сделайте оба.)
3. **Проверить PHP** на поддомене: версия 7.4+ (нужна для `api/submit.php`).
4. **Почта отправки:** завести ящик на домене (напр. `noreply@easy-1c.ru`) и
   убедиться, что для домена включены **SPF и DKIM** — иначе письма о заявках уйдут в спам.
5. **Взять SFTP-доступ:** хост, логин, пароль (или ключ), порт — из раздела «Доступ по SSH/FTP».

## B. Разовая настройка локально (в Claude Code Desktop)

1. Склонировать этот репозиторий и переключиться на ветку `claude/landing-pages-forms-analytics-snykxd`.
2. Настроить деплой:
   ```bash
   cd landing-kit
   cp deploy.config.example deploy.config     # вписать SFTP-доступ и REMOTE_DIR
   cp api/config.example.php api/config.php    # вписать mail_to / mail_from
   brew install lftp                           # если ещё не стоит
   ```
3. Вставить счётчик Яндекс.Метрики в `index.html` (заменить `00000000` в трёх местах)
   и создать в Метрике цель типа «JavaScript-событие» с идентификатором `lead`.

> `deploy.config`, `api/config.php`, CSV с заявками — в `.gitignore`, в репозиторий не попадут.

## C. Цикл создания лендинга (повторяется для каждого)

1. **Дизайн (Claude Design / артефакт).** Дать Claude описание из вашего Dropbox
   (`.../Цифра/Маркетинг/okk-landing`) → собрать визуал странички, отполировать внешний вид.
2. **Перенос в каркас (Claude Code).** Попросить перенести утверждённый дизайн в
   `landing-kit`: цвета/шрифты → `tokens.css`, подключить готовую форму, Метрику,
   согласие 152-ФЗ. Логика формы и бэкенд уже готовы — трогать не нужно.
3. **Локальное превью.** Открыть `index.html` в браузере, проверить вид и адаптив.
4. **Публикация:**
   ```bash
   bash deploy.sh
   ```
   Скрипт зальёт файлы на okk.easy-1c.ru по SFTP, не трогая папку с заявками.
5. **Проверка боевого:** открыть https://okk.easy-1c.ru → отправить тестовую заявку →
   убедиться, что пришло письмо, заявка легла в `api/data/leads-ГГГГ-ММ.csv` на сервере,
   и цель `lead` зафиксировалась в Метрике.

**Новый лендинг = копия `index.html` → тот же цикл C.** Стиль подтянется сам (он весь в `tokens.css`).
